# ML-DataVisulisation
# Machine Learning: Visualisation and Clustering

A Python-based Jupyter Notebook exploring fundamental machine learning concepts, including probability, Bayesian inference, clustering, dimensionality reduction, and model evaluation.

## Topics Covered

- **Probability and Bayesian Inference:** Probability calculations and Naive Bayes classification.
- **Clustering:** K-Means, DBSCAN, Gaussian Mixture Models, and Bisecting K-Means.
- **Dimensionality Reduction:** Principal Component Analysis (PCA), t-SNE, and UMAP.
- **Data Visualisation:** Visualising high-dimensional datasets in two-dimensional space.
- **Model Evaluation:** Silhouette scores, Davies–Bouldin scores, accuracy, precision, recall, and confusion matrices.
- **Classification:** Evaluating model performance, overfitting, and generalisation.

## Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Dataset

The notebook uses the Fashion-MNIST dataset for clustering and dimensionality reduction exercises.

## Getting Started

1. Clone this repository.
2. Install the required Python libraries.
3. Download the Fashion-MNIST dataset where required.
4. Update any local dataset paths in the notebook.
5. Open `ML 2 visualisation practice.ipynb` in Jupyter Notebook or VS Code and run the cells.

Install the main dependencies with:

```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```

## Purpose

This project demonstrates practical application of machine learning algorithms, exploratory data visualisation, dimensionality reduction, and model evaluation as part of undergraduate Data Science coursework.
